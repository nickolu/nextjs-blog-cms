# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-01-26

### Added
- Initial release of Blog CMS
- Browser-based CMS using File System Access API
- WYSIWYG editor powered by TipTap
- MDX and Markdown support with frontmatter parsing
- Real-time validation for required fields
- Draft mode to mark posts as drafts
- Search and filter functionality
- Keyboard shortcuts (Ctrl+S / Cmd+S to save)
- Persistent directory selection using IndexedDB
- AI-powered autocomplete using OpenAI API
- Configurable AI model selection
- Smart caching for AI suggestions
- Settings dialog for AI configuration
- Review dialog for post metadata
- Support for rich text formatting (bold, italic, headings, lists)
- Code blocks with syntax highlighting
- Link and image support
- Undo/redo functionality

### Documentation
- Comprehensive README with features and setup instructions
- Quick start guide
- AI autocomplete documentation
- Environment configuration examples

### Browser Support
- Chrome 86+
- Edge 86+
- Opera 72+
